# **App Name**: Cambodia Hub

## Core Features:

- Animated Searchbox: Display a stylish searchbox with smooth animations and an integrated enter button.
- Data Fetch: Ability to call data on search criteria

## Style Guidelines:

- Primary color: Rich Crimson (#D71333), evocative of the Cambodian flag and culture.
- Background color: Soft Beige (#F5F5DC), provides a warm, neutral backdrop.
- Accent color: Golden Yellow (#FFD700), symbolizing prosperity and heritage, used sparingly for highlights.
- Font: 'Inter', a versatile sans-serif font, will be used for both headers and body text.
- The search box should take up most of the horizontal real estate, as appropriate.
- Subtle animation on the searchbox for focus, key presses and hitting 'enter'.
