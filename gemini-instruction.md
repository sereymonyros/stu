## My Coding Style and Preferences

This document outlines my preferences for coding style. Please follow these guidelines when making changes to my code.

### General
- Add comments to explain complex logic.
- Keep functions short and focused on a single task.
- Use descriptive variable names.
- folders are the features, and folders are the routes
- each folder has it own page.tsx, error.tsx. And other sub files are the children of page.tsx

### React
- Prefer functional components with hooks over class components.
- Use TypeScript for all new components.
- Structure files with the component at the top, followed by styles, and then any helper functions.

### AI
- When using generative AI, please make sure the responses are concise and helpful.
- when I type D) meaning i need to consult with AI, i need advise from AI. Please do not code yet when you texts start with D)
